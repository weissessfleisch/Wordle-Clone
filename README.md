## 🚀 Kurulum ve Oynanış (Nasıl İndirilir?)

Bu projeyi bilgisayarınızda çalıştırmak için aşağıdaki iki yöntemden size uygun olanı seçebilirsiniz:

### 🎮 Sadece Oynamak İsteyenler İçin (Önerilen Yöntem)
Bilgisayarınıza Visual Studio veya herhangi bir programlama aracı kurmanıza gerek yoktur. Doğrudan oyunu oynamak için:
1. Sayfanın sağ tarafında bulunan **[Releases](https://github.com/weissessfleisch/Wordle-Clone/releases/latest)** (Sürümler) sekmesine tıklayın.
2. Açılan sayfada en güncel sürümün (Örn: `v1.0.0`) altında bulunan **Assets** kısmından proje arşivini (`.zip` veya `.rar`) bilgisayarınıza indirin.
3. İndirdiğiniz arşivi klasöre çıkartın ve içindeki `.exe` uzantılı oyun dosyasına çift tıklayarak hemen oynamaya başlayın!

### 💻 Geliştiriciler ve Eğitmenler İçin (Kaynak Kodunu Çalıştırma)
Projenin kaynak kodlarını incelemek veya üzerinde değişiklik yapmak isterseniz:
1. Sayfanın sağ üst köşesindeki yeşil renkli **"<> Code"** butonuna tıklayın.
2. **"Download ZIP"** seçeneğini seçerek proje dosyalarını indirin.
3. İndirdiğiniz arşivi klasöre çıkartın ve içindeki `.sln` (Solution) dosyasına çift tıklayarak projeyi **Visual Studio** ile açın.
4. Üst menüdeki `Start` (Başlat) butonuna basarak projeyi derleyip test edebilirsiniz.
